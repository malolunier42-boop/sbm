# S.B.M. Décor Stylisé

Site vitrine français responsive, sans backend ni collecte de données. Illustrations SVG originales et polices locales (licences dans `public/fonts`).

## Développement

Node.js 20.19+ ou 22.12+.

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Déployer le dossier `dist` sur un hébergement statique HTTPS.

## Avant publication

Faire valider par l’entreprise les prestations proposées, les coordonnées et horaires. Ajouter les mentions légales complètes (identité juridique, SIRET, responsable de publication, hébergeur). Les illustrations d’inspiration ne sont pas des réalisations S.B.M. Aucune note, ancienneté ou certification n’est revendiquée. Le contact fonctionne par lien téléphonique ; aucun formulaire ne prétend envoyer de message.

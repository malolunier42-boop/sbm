Votre dossier de projet est préparé sur votre appareil, sans envoi automatique à S.B.M. Les configurations se retrouvent dans leur lien, sans vos coordonnées. Cette version n’intègre ni publicité ni outil de mesure d’audience. Les polices et les composants 3D sont servis avec le site.

02. Consultation et données techniques

Vous pouvez consulter les pages sans créer de compte et sans renseigner votre identité. Le site ne comporte pas de suivi publicitaire ni d’outil de mesure d’audience et ne dépose pas de cookie depuis son code.

Comme pour tout site web, votre navigateur communique des informations techniques au service d’hébergement pour obtenir les pages : notamment une adresse IP, l’adresse de la ressource demandée et des informations sur le navigateur. Lorsqu’un lien de configuration est ouvert, ses paramètres d’URL font partie de l’adresse demandée et peuvent donc apparaître dans les journaux techniques de l’hébergeur. Ces paramètres décrivent l’escalier et le profil particulier ou professionnel, sans les coordonnées saisies dans le dossier. L’hébergeur peut traiter ces informations pour délivrer et sécuriser son service, selon ses propres règles.

Le site utilise GitHub Pages, service de GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, États-Unis. Les finalités, destinataires, modalités de conservation et éventuels transferts liés au service d’hébergement sont présentés dans la déclaration de confidentialité officielle de GitHub , consultée le 16 octobre 2026. Pour une question sur les données traitées par GitHub, vous pouvez utiliser son formulaire de contact relatif à la confidentialité . Cette page ne fixe pas de durée de conservation à la place de l’hébergeur.

03. Votre configuration 3D et son lien

Les réglages de forme, de dimensions indicatives, de matières, de couleurs et d’options sont gérés dans la page. Lorsque vous les modifiez dans le configurateur, les choix sont aussi inscrits dans l’URL, avec le profil particulier ou professionnel. Ils peuvent ainsi être retrouvés en rechargeant la même adresse, en l’ajoutant aux favoris ou en partageant le lien. Le site n’ajoute à ce lien ni nom, ni téléphone, ni e-mail, ni entreprise, ni texte personnel du formulaire.

Le lien peut rester dans l’historique ou les favoris de votre navigateur et être consulté par les personnes auxquelles vous le transmettez. Le bouton de partage copie ce lien dans le presse-papiers à votre demande ; il ne le publie pas et ne l’envoie pas à l’atelier. Le code du site n’enregistre pas de configuration dans un compte, dans une base de données de S.B.M., dans le stockage local (localStorage) ou dans le stockage de session (sessionStorage) du navigateur.

Les vues 3D sont des études d’intention. Elles ne représentent pas des réalisations attestées de S.B.M. et ne valent ni étude technique, ni validation de conformité, ni devis. Les choix sauvegardés dans le lien ne constituent pas une commande.

04. Le dossier préparé sur votre appareil

La page Préparer mon devis permet de renseigner votre profil, votre nom et votre téléphone ainsi que, pour un professionnel, votre entreprise ou agence. Vous pouvez aussi préciser un e-mail, le lieu du projet, son contexte, l’horizon souhaité, votre budget envisagé, des variantes de matières et un message. Ces informations servent à composer votre dossier de discussion avec l’atelier ; le budget saisi n’est pas une estimation de prix du site.

Le bouton « Préparer ma demande » réalise cette mise en forme dans votre navigateur. Il n’effectue aucun envoi, ne crée aucune entrée dans une base de données de l’entreprise et ne génère aucun accusé de réception de S.B.M. Les champs de coordonnées et le message ne sont pas ajoutés à l’URL. Le lien de configuration contenu dans le dossier reprend uniquement les choix de l’escalier et le type de client.

Vous pouvez ensuite, par une action explicite, télécharger le dossier au format texte, l’imprimer ou le copier dans votre presse-papiers. Ces exports contiennent les coordonnées et les informations que vous avez renseignées. Le nom du fichier téléchargé peut reprendre votre nom. Conservez, partagez ou supprimez ces fichiers, impressions et copies avec les moyens de votre appareil. L’impression en PDF ou la synchronisation de votre presse-papiers dépend de votre navigateur, de votre système et de vos réglages.

Sans export de votre part, le code du site conserve les informations du formulaire uniquement dans la page en cours. Il ne les enregistre ni dans des cookies, ni dans le stockage local ou de session du navigateur. Votre navigateur peut néanmoins proposer de mémoriser ou de rétablir des champs avec ses fonctions de saisie automatique ou de restauration de page ; vous gérez ces fonctions dans ses paramètres.

Pour transmettre le dossier et organiser l’étude du projet, appelez l’atelier au 04 77 50 15 65 puis utilisez le moyen de transmission convenu avec lui. Télécharger, copier ou imprimer ne transmet pas le dossier à l’entreprise.
